# 使用指南

> 面向新用户。读一遍就能把一份 `.docx` 变成模型能读、能改、能回写的东西。
> 版本:`dshm-tools-docx` 0.7.0。

## 一、装在哪

插件按 profile 加载;产物落**项目存储**(`dshm-desktop/docs/存储布局.md` §3/§4):

```
<项目根>/.dshm/docx/<文件名>-<源文件 sha256 前 8 位>[-样式][-编辑]/
```

- 项目根从哪来:工具参数 `project`;省略时反推当前会话工作区;**推不出来直接报错**,不会猜当前目录。
- 同一份文件重转命中缓存(不重解析);文件一改,指纹变,落到新目录。
- 三种版本**并存**,互不覆盖:`-样式`、`-编辑`、`-样式编辑`。

## 二、两个工具

### 2.1 `doc_convert`:docx → 产物目录

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `file` | ✅ | — | `.docx` 路径(绝对,或相对项目根) |
| `project` | | 会话工作区 | 项目根;产物落 `<project>/.dshm/docx/` |
| `force` | | false | 忽略缓存重转 |
| `images` | | true | 是否把图片导出成 `media/` 文件 |
| `split` | | true | 是否按标题拆 `chapters/`(每章 ≤800 行) |
| `styles` | | false | 输出带样式版本(格式标记) |
| `edit` | | false | 输出可编辑版本(`content.xml` + `raw/`) |

返回:`outDir`、`index`、`content`、`stats`、`missing`、`chapters`、`styled`、`editable`、`cached`。

### 2.2 `doc_build`:产物目录 → docx

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `dir` | ✅ | 可编辑产物目录(`doc_convert` 带 `edit:true` 返回的 `outDir`) |
| `out` | | 输出路径;省略写到该目录下的 `重建.docx` |

返回:`outFile`、`bytes`、`hint`。

## 三、产物结构

```
<项目根>/.dshm/docx/年报-a1b2c3d4/
├─ index.md          ← 先读这个:大纲 / 统计 / 图片清单 / 不可得项 / 怎么读
├─ content.md        ← 全文(便于 grep;按块顺序)
├─ chapters/         ← 每章一个文件,≤800 行(一次 read 能吃完)
├─ media/            ← 图片附件 001.png、002.emf…
├─ manifest.json     ← 源指纹 + 选项 + 转换器版本(缓存判断)
├─ styles.md         ← 仅 styles:true:样式类表(类 → 声明 → 次数)
├─ content.xml       ← 仅 edit:true:可编辑视图
└─ raw/原文档.docx    ← 仅 edit:true:回写母版
```

### 3.1 `content.md` 里会看到什么

| 写法 | 含义 |
| --- | --- |
| `# 标题` ~ `####` | 标题层级(由样式链与 `outlineLvl` 求解) |
| `- 项` / `1.` / `a)` / `一、` | 列表(序号是按 `numbering.xml` 推算的真实序号) |
| `| 表 | 格 |` 或 `<table>` | 表格;有合并/嵌套时退 HTML |
| `$...$` / `$$...$$` | OMML 公式 → LaTeX |
| `![alt](media/001.png)` + `<!-- image: … -->` | 图片 + 机器可读元信息(尺寸/格式/是否浮动) |
| `[^1]` + 文末 `## 脚注` | 脚注 / 尾注 |
| `## 批注` + `- **[id] 作者 · 时间**:…` | 批注(回复/已解决会标出来) |
| `〔内容控件:…〕` / `〔文本框:…〕` / `〔图表:…〕` / `〔SmartArt〕` | 已建模的其它对象 |
| `〔样式:14pt #C00000 宋体〕` / `〔s1〕` | 仅带样式版本:格式标记(重复的收成类 `s1`) |
| `〔不可得:页码(PAGE 域) 原值="3"〕` | 读不到的东西,如实标出,不静默丢 |

### 3.2 `index.md` 里有什么

源文件指纹、统计(段落/标题/表格/图片/公式/脚注/批注/修订/控件/分节)、文档属性(作者/字数/自定义属性)、
大纲(章 → 文件 → 行数)、图片清单、表格清单、图表清单、公式前 20、书签、**不可得清单**、"怎么读"。

## 四、常见场景

### 4.1 只想搞清楚这份文档讲什么

```text
doc_convert({ file })
read <outDir>/index.md          ← 大纲 + 属性 + 统计
```

### 4.2 找某个细节

```text
grep "关键词" <outDir>/content.md
```

### 4.3 大文档按章读

`index.md` 的「大纲」给出每章文件与行数;直接 `read chapters/03-….md`。
每章都 ≤800 行,一次 `read` 能吃完。

### 4.4 看图片

正文里是相对引用:走 `read_image <outDir 绝对路径>/media/001.png`。
`index.md` 的「图片清单」列了尺寸/类型/替代文字。

### 4.5 要颜色/字号/字体

```text
doc_convert({ file, styles: true })
```
带样式版会标 `〔样式:14pt #C00000 宋体〕`;**出现 ≥2 次**的声明收成样式类(`〔s1〕`),
声明集中在 `styles.md`,每个 `content.md` / 章文件顶部有一张"本文件用到的类"小表。

### 4.6 改文档再交付

```text
1) doc_convert({ file, edit: true })
2) read/改 <outDir>/content.xml
3) doc_build({ dir: outDir })      → 写出 重建.docx
4) present({ files: [{ path: "<outDir>/重建.docx" }] })
```

`content.xml` 的写法见 [能力矩阵](能力矩阵.md) 与 [设计](设计.md);
一句话:**元素名就是 OOXML 元素名,属性扁平化,值写人话**(`0.5in` / `14pt` / `1.5x` / `#C00000`)。

改动安全线:

- 带 `w:readonly="1"` 的块**改了不生效**(回写时整段从 raw 搬回)。
- 删掉整块 = 回写时该块消失;新增块请复制同类块的形状再改。
- 改完先用 `doc_build` 回写,再 `doc_convert` 转一遍,看 `content.md` 是否符合预期。

### 4.7 整体排版(示例:改成学术论文格式)

`test/format-paper.js` 就是一份可复制的样板 —— **只改 `content.xml` 的属性**,文字一字不动:

```bash
node test/format-paper.js <可编辑产物目录>
# → 同目录下 论文格式.docx
```

它做的事:

- **页面**:A4;页边距 上 30 / 下 25 / 左 30 / 右 25 mm;页眉距顶 15mm、页脚距底 17.5mm;装订线 0;
  文档网格「每页 40 行」(行距 343 缇);正文页码从 1 起。
- **标题**:三级黑体 22 / 16 / 14pt;一级居中且章前分页;标题不叠加粗体(黑体本身即强调)。
- **正文**:宋体小四、两端对齐、1.5 倍行距、首行缩进 2 字符(480 缇)、段后 6pt。
- **表格**:整体居中、表内五号、表头加粗、嵌套表同样处理。
- **图表题注**:五号居中;空段落压掉间距;首字下沉收到一号(26pt)。
- **打开方式**:把文档默认视图设为**页面视图**(`settings.xml` 的 `w:view="print"`)—— 论文必须按页看,
  收件人一打开就是分页显示,不用自己切视图。

校验"只改格式、没动文字":`node test/verify-format.js <原产物目录> <排版后 docx>`。

## 五、排错

| 现象 | 原因 / 处理 |
| --- | --- |
| `这是 .doc(Word 97-2003)二进制格式…` | 只吃 `.docx`;用 Word/WPS 另存为 `.docx` |
| `拿不到项目目录:请在 project 参数里显式给出项目根路径` | 会话工作区没解析出来;显式传 `project` |
| 产物里出现 `〔不可得:…〕` | 那一类内容本来就拿不到(页码/EMF 像素/OLE 内部);不是 bug |
| 带样式版看不到某个格式 | 只标注**非默认**属性;与文档默认一致的不标 |
| 改了 `content.xml` 没生效 | 那个块是 `w:readonly="1"`;或你改的是 `w:anchor` 之下的只读文本 |
| `doc_build` 报找不到 `content.xml` | 目录不是可编辑产物;先 `doc_convert({ edit: true })` |
| Word 打开提示修复 | 某个只读块在 raw 里对不上锚点;把对应 `w:readonly` 去掉后重写,或用 `force` 重转 |
| 打开是"一张拉不完的长纸",看不到分页 | 当前是 **Web 版式**(文档里存着 `<w:view w:val="web"/>`)。切 `视图 → 页面视图` 即可。**论文/报告必须按页看** —— 视图模式是读者端设置,工具不会替你改文件 |

## 六、还没做的(别当 bug)

- `.doc` / `.xls` / `.ppt` 老格式、`.xlsx` / `.pptx` 新格式。
- EMF/WMF 栅格化(`read_image` 不认这两种)。
- 图表 / SmartArt / OLE 的专用编辑器(现在只读)。
- 页眉页脚 / 脚注 / 批注部件的重建(现在原样继承,其中文字改不了)。
- 页码、自动分页位置(值由排版决定,不回写)。
