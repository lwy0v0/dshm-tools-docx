# 能力矩阵:每个元素能读什么、能改什么、能写回什么

> 面向维护者与新用户。**全部以代码为准**(每行给实现位置),不是设想。
> 版本:`dshm-tools-doc` 0.4.0。改代码后请同步改本表 —— 表与代码漂了,后面就没法维护。

## 记号

| 记号 | 含义 |
| --- | --- |
| 可读 | 解析层产出的字段(`content.md` 能体现 / 对象模型里有) |
| 可编辑 | 在 `content.xml` 里能改的部分;**没列的属性回写时从 `raw/` 原样继承** |
| 可写 | 🔁 重建 · 📎 原样回填(`w:readonly="1"`) · ⊘ 不写(部件原样继承) |
| 位置 | 实现文件(`src/` 相对路径)+ 关键类/函数 |

## 一、块级元素

| 元素 | 可读 | 可编辑 | 可写 | 位置 |
| --- | --- | --- | --- | --- |
| 标题 | 级别、样式名、文本与格式、版式、锚 | 文本、`w:pStyle`、对齐、缩进、行距、分页控制、编号 | 🔁 | `word/blocks/paragraph.js` · `word/layout/paragraph.js` |
| 段落 | 文本与格式、样式名、版式、锚 | 同上(标题以外) | 🔁 | 同上 |
| 列表 | 层级、**真实序号**(标签)、有序/无序、文本、版式 | 文本、`w:numId` / `w:ilvl`(换列表)、缩进与行距 | 🔁 | `word/blocks/paragraph.js` · `word/numbering.js` |
| 表格 | 行/格、跨列、纵向合并、列宽、表宽、表宽类型、布局、行高/高规则/表头/不断页、格宽、格底纹、文字方向、垂直对齐、斜线、边框(表级)、题注/说明、锚 | 行列结构、`w:gridSpan`、`w:vMerge=restart`、列宽、行高、表头、格宽、格底纹 | 🔁(表级边框取自 raw;单元格边框不重建) | `word/blocks/table.js` · `word/layout/table.js` |
| 分节 | 纸张(宽高/方向)、页边距(上下左右)、**页眉页脚距/装订线/竖直对齐**、栏数、分节类型、**文档网格(行距、每页行数)**、**首页不同**、页码起始、页眉页脚引用、锚 | 纸张宽高/方向、四条页边距、页眉页脚距、装订线、竖直对齐、栏数、分节类型、文档网格、首页不同、页码起始 | 🔁(页面设置重建;页眉页脚引用等其余子元素取自 raw) | `word/blocks/section.js` · `edit/build.js 重建分节()` |
| 内容控件(SDT) | 9 类类型、标签、值、勾选状态、可选项、日期格式、部件库名、数据绑定(xpath/storeItemID) | 只读 | 📎 | `word/sdt.js` · `document.js 成内容控件()` |
| 文本框 | 内部块、定位(相对/偏移/对齐/环绕/锁定)、替代文字、锚 | 只读(整段) | 📎 | `word/blocks/fragment.js 解析绘图或对象()` · `word/drawing.js` |
| 图表 | 类型(bar/line…)、系列名/分类/数值(来自 `c:numCache`) | 只读 | 📎 | `word/blocks/embed.js 读图表()` |
| SmartArt | 各节点文字(`dgm:pt/dgm:t`) | 只读 | 📎 | `word/blocks/embed.js 读智能图形()` |
| 嵌入对象(OLE) | ProgID、类型说明(MathType/Excel/Visio/包) | 只读 | 📎 | `word/blocks/embed.js 解析嵌入()` |
| 修订区 | 修改类型(新增/删除)、作者、时间、内部块 | 文本、内部块结构 | 🔁 | `document.js 成修订区()` |
| 页眉页脚 | 位置(页眉/页脚)、作用域(默认/首页/偶数页)、部件路径、内部块 | 只读 | ⊘ 部件原样继承 | `word/blocks/section.js 解析页眉页脚()` |
| 注释区(脚注/尾注) | 注型、标号、正文块(含其中的公式/图片) | 只读 | ⊘ 部件原样继承;正文引用 🔁 | `word/blocks/footnote.js` |
| 批注区 | id、作者、首字母、时间、段落 paraId、回复于、已解决、内容块 | 只读 | ⊘ 部件原样继承;引用随段落回填 | `word/blocks/comment.js` |
| 不可得 | 原因、原值、提示(如页码域) | 只读 | 📎(所在段落整段只读) | `word/inline/runs.js 输出域记录()` |

| 片段 | 可读 | 可编辑 | 可写 | 位置 |
| --- | --- | --- | --- | --- |
| 文本 | 文本 + 全套格式(下表) | 文本、全部格式属性、超链接 | 🔁 | `word/inline/runs.js` · `format.js` · `edit/writer.js` |
| 图片 | 路径、媒体部件、替代文字、宽高、是否浮动、**定位**(方式/相对H·V/偏移/对齐/环绕/在文字下方/锁定)、**裁剪**、**变换**(旋转/翻转/偏移/尺寸) | 尺寸、裁剪、旋转、位置(相对/偏移/对齐/环绕)、替代文字、是否浮动 | 🔁(媒体字节取自 raw;无法新增图片) | `word/blocks/image.js` · `word/drawing.js` · `edit/writer.js 图片属性()` |

| 脚注引用 | 标号、注型、原始 `w:id` | 只读 | 🔁(引用重建,注文来自原部件) | `word/blocks/fragment.js` · `edit/build.js` |
| 内容控件(行内) | 同内容控件 | 只读 | 📎 | `word/sdt.js` |

| 链接(域形态的 `HYPERLINK`) | 目标 URL + 结果文字 | 文本、目标 | 🔁 | `word/fields.js` · `edit/build.js 取链接关系()` |
| 不可得 | 原因/原值 | 只读 | 📎 | `word/blocks/fragment.js` |

## 三、字符格式(文本片段字段)

全部**可读可编辑可写**(🔁),位置 `word/inline/format.js`(读)↔ `edit/build.js 造run属性()`(写)。

| 属性 | 读自 | 在 content.xml 里 |
| --- | --- | --- |
| 粗 / 斜 / 删除线 | `w:b` `w:i` `w:strike` `w:dstrike` | `w:b="1"` `w:i="1"` `w:strike="1"` |
| 下划线(含类型) | `w:u` | `w:u="single"` / `="double"` … |
| 上标 / 下标 | `w:vertAlign` | `w:vertAlign="superscript"` |
| 隐藏文字 | `w:vanish` | `w:vanish="1"`(正文不显示,回写保留) |
| 字号 | `w:sz`(半磅) | `w:sz="14pt"` |
| 颜色 | `w:color` | `w:color="#C00000"` |
| 字体(中西文) | `w:rFonts`(eastAsia 优先) | `w:font="宋体"` |
| 高亮 / 底纹 | `w:highlight` / `w:shd` | `w:highlight="yellow"` / `w:shd="#EEEEEE"` |
| 字符样式 | `w:rStyle` | `w:rStyle="Strong"` |
| 字间距 / 缩放 / 升降 | `w:spacing` / `w:w` / `w:position` | `w:spacing="2pt"` / `w:scale="150%"` / `w:position="3pt"` |
| 全大写 / 小型大写 / 着重号 | `w:caps` / `w:smallCaps` / `w:em` | `w:caps="1"` / `w:em="dot"` |
| 超链接 | `w:hyperlink @r:id`(外部)/ `@w:anchor`(内部) | `<w:hyperlink w:target="https://…">` |

## 四、段落版式(可读可编辑可写)

位置 `word/layout/paragraph.js`(读)↔ `edit/build.js 造段落属性()`(写)。

| 项 | 读自 | 在 content.xml 里 |
| --- | --- | --- |
| 对齐 | `w:jc` | `w:jc="center"` |
| 缩进(左/右/首行/悬挂) | `w:ind` | `w:ind-left="0.5in"` 等 |
| 行距 / 段前段后 | `w:spacing` | `w:spacing-line="1.5x"`、`w:spacing-before="6pt"` |
| 分页前 / 与下段同页 | `w:pageBreakBefore` / `w:keepNext` | `w:pageBreakBefore="1"` |
| 编号引用 | `w:numPr` | `w:numId="2" w:ilvl="1"` + `w:listLabel="a)"`(标签只读展示) |
| 段落样式 | `w:pStyle` | `w:pStyle="heading 1"` |
| 首字下沉 | `w:framePr @dropCap` / `@lines` | `w:frame-drop="drop" w:frame-lines="3"`(其余框架属性仍取自 raw) |
| 边框 / 底纹 | `w:pBdr` / `w:shd` | **可读,不可编辑**;回写从 raw 继承 |
| 制表位 | `w:tabs` | 同上 |
| 框架(`w:framePr`)位置/尺寸 | 宽高/偏移/基准/环绕 | 同上 |
| 段落标记格式(`w:pPr/w:rPr`) | 不建模 | **不继承**:不回写,避免改过字号的段落留着旧行高 |
| 大纲级别 | `w:outlineLvl` | 由样式推断;回写从 raw 继承 |

## 五、读不到 / 不重建(都是有意的)

| 东西 | 状态 | 原因 |
| --- | --- | --- |
| 页码(`PAGE`/`NUMPAGES`/`SECTIONPAGES`/`PAGEREF`) | 标 `〔不可得:页码(… 域)〕` | 值由排版决定,缓存值不可信 |
| 自动分页位置 | 读不到 | OOXML 无分页信息 |
| `w:sym` 符号字符 | 只给 `[符号 字体/码位]` | 没有字形映射表,反解不出真字符 |
| EMF / WMF 像素 | 只导出文件 | 无解码器,`read_image` 不认 |
| 加密包 / 宏 / 数字签名 / ActiveX | 只报"有" | 无结构可读或不执行 |
| 水印 | 未识别 | 页眉里的 `v:shape` + 文字路径组合 |
| 图表 / SmartArt / OLE | 数据可读,**不重建** | 需要专用编辑器(见下) |
| 页眉页脚 / 脚注 / 批注部件 | 内容可读,**不重建** | 第一版靠原样继承保住引用 |

## 六、扩展路线(为什么说"能补")

每一行都已有数据基础(锚点 + `raw/` 母版),扩展时只需**给那一类对象加专用编辑器**,
回写框架、锚点机制、样式表都不用动。

| 对象 | 要做的三件事 | 难度 | 已有基础 |
| --- | --- | --- | --- |
| 图表 | content.xml 给数据表 → 写回改 `c:numCache` → 样式仍原样回填 | 中 | 系列数据已解析 |
| SmartArt | 节点树摊成缩进列表 → 写回改 `dgm:pt/dgm:t` | 中 | 节点文字已解析 |
| OLE / MathType | 按 ProgID 分派专用解析器(公式可解成 LaTeX) | 高 | ProgID 已解析 |
| 水印 | 识别 `v:textpath`,当页眉文字编辑 | 低 | 页眉已解析 |
| TOC | 只允许改指令 → 回写标 dirty 让 Word 重算 | 中 | 域清单带指令与锚 |
| 域结果 | 改缓存值 + 清 `dirty` | 低 | 域清单带 `需重算` |
| 批注回复 | 新建时分配 paraId 并写 `commentsExtended` | 中 | paraId 父子已解析 |
| 页眉页脚部件 | 与正文同一套重建逻辑,但要各自独立 rels | 中 | 版式与块模型已通用 |

## 七、验收锚点

改任何一块能力后,跑:

```
node test/verify-full.js        # 175 项断言(夹具覆盖每个块/片段/版式字段)
node test/roundtrip.js <docx>   # 真实文档往返:正文逐行比 + 统计比
```

`verify-full.js` 里的断言名与本表的行是**一一对应**的;新增能力时:夹具加内容 → 断言加一条 → 本表加一行。
